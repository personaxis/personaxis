# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub:
[Report a vulnerability](https://github.com/personaxis/personaxis/security/advisories/new).

Include what you found, how to reproduce it, and which version or commit it affects. Only the maintainers see the report until a fix is published.

## Supported versions

Fixes go to the latest release. The current line is `0.17.x`, and the specification it implements is `1.1.0`.
