# `personaxis card`

Print a shareable card for a persona: its name and role, spec version, the sigil glyph
generated from its spec, how many state mutations it has recorded, and the SHA-256 of its
spec file.

```bash
personaxis card
personaxis card --json     # the same data machine-readable
personaxis card --persona .personaxis/personas/cmo/personaxis.md
```
