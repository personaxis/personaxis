# `personaxis card`

Print a shareable persona card: the aura/sigil plus verifiable stats (spec hash, drift,
mutations, memory-chain status).

```bash
personaxis card
personaxis card --json     # the same data machine-readable
personaxis card --persona .personaxis/personas/cmo/personaxis.md
```

The card is the human-friendly face of the trust surface; the machine-friendly ones are
`personaxis attest` (credential) and `personaxis verify` (integrity).
