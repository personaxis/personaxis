# `personaxis list`

List the sub-personas installed in THIS project (`.personaxis/personas/`), one line each.

- **Inside the app:** the Persona miniapp's **Sub-personas** tab (`/persona`) shows the same
  roster as navigable rows with a per-sub card (model, state, how to address it).
- **Outside (agents/CI):**

```bash
personaxis list
```

See also: `personaxis personas` (tree with addresses), `personaxis template` (authoring
scaffolds), `personaxis ps` (which personas are awake).
