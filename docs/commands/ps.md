# `personaxis ps`

Fleet view for THIS project: which personas are awake or idle, mutation counts, tone and
last activity, from their `state.json` and live presence files.

```bash
personaxis ps
```

- **Inside the app:** the Command Center's **Fleet** section shows the same, live, with
  drill-down; press `g` for the all-projects scope (global registry).
- Presence comes from `.live.json` heartbeats written by running sessions.
