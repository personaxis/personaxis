# `personaxis template`

Pedagogical templates: ready-made `personaxis.md` scaffolds you can read or start from.

```bash
personaxis template            # list available templates
personaxis template <name>     # print one to stdout
personaxis template <name> > .personaxis/personaxis.md   # start from it
```

Templates are teaching material: every field carries its tier (MUST/SHOULD/MAY) and consumer
comments. For creating a persona interactively, prefer `personaxis create` (the Genesis
wizard compiles and polishes for you).
